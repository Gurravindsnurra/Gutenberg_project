Strukturen som jag har valt har jag gjort för att jag vill ha en minimalistisk och ganska enkel sida att ta sig runt på. Jag har valt att ha navigeringen längst upp på sidan och med position fixed så att man alltid kan komma åt navigeringen. Färgen grön valde jag för att jag tyckte att den passade till boken som hemsidan handlar om men länkarna i navigeringen som är blå från början var jag tvungen att ändra till vit för att kontrasten skulle bli bättre.

När jag körde koden genom validator.nu fick jag några felkoder där jag hade använt mellanrum i id:n vilket jag fixade. Min CSS hade inga felkoder.

Om jag hade haft en vecka till hade jag försökt att göra sidan lite snyggare.

Det jag hadde velat lära mig mer om är hur man kan göra layouten mer avancerad med olika delar som kan expanderas.
